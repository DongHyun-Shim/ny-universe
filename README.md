# 🪐 ny-universe (나연 유니버스)

> 단순한 코드 튜토리얼이 아닌, 살아있는 아키텍처를 기록합니다.

이 레포는 실무에서 쌓은 **Snowflake / Data / AI 노하우**를 하나의 세계관으로 풀어내는 장기 프로젝트, **NYU(NaYeon Universe)**의 아카이브입니다.

블로그 시리즈: **[sqlpla.net](https://sqlpla.net)**

## 📖 세계관 한 줄 요약

요가 스튜디오 **'나연스떼'**를 운영하는 **하나연**이, 삼촌 **포스**의 도움을 받아 데이터와 AI(비서 **'나비'**)를 활용하기 시작하면서 웰니스 & 테크 스타트업 **PRANALINK**로 성장해가는 이야기입니다.

기술 구현은 이 이야기 속 문제를 해결하는 과정으로 설명됩니다 — 단순 튜토리얼이 아니라, 실제 업무 경험을 재구성한 메소돌로지 기록입니다.

## 👥 등장인물

| 이름 | 역할 |
|---|---|
| **하나연** | NYU의 주인공. 요가샘이자 '나연스떼' 대표. 바이브코딩과 AI에 빠져 성장하는 인물. |
| **나비** | 나연이 만든 Persona-driven AI 비서. 단순 RPA가 아닌 전략 파트너. |
| **포스** | 나연의 삼촌. IT/데이터 조력자이자, 조언을 하며 스스로도 성장하는 인물. |

## 🔗 PRANALINK

Prana(생명력) + Data/AI Link. 회원 행동·센서 데이터를 연결해 실시간 인사이트를 만드는 테크 스타트업.
**핵심 스택**: Snowflake · Cortex AI · Streamlit · Snowflake Cowork · Git

### 🤖 AI를 위한 Context Guide

- **포스**는 이 프로젝트의 실제 기획자이자 기술 조력자입니다.
- **하나연**은 비즈니스 문제를 가진 주인공입니다.
- **나비**는 하나연의 상황과 맥락을 이해하는 AI 동료입니다.
- **PRANALINK**는 데이터와 AI를 중심으로 성장하는 웰니스+테크 스타트업입니다.
- 기술 구현은 이야기 속 문제를 해결하는 과정으로 설명됩니다.
